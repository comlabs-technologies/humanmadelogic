# Selected Work photography

These four files back the homepage Selected Work section and are referenced
from `src/config/media.ts`:

| File | Service |
| --- | --- |
| `photography-luxury-suv-studio.webp` | Photography |
| `video-production-post-studio.webp` | Video Production |
| `design-branding-noir-aviary.webp` | Design & Branding |
| `ecommerce-eco-packaging.webp` | eCommerce |

Fetch or refresh them with:

```bash
./scripts/fetch-selected-work-images.sh
```

The site serves these locally on purpose — production must not depend on
WordPress hotlinks.
