# Relay — Editorial AI SaaS Template for Next.js

A configurable editorial landing-page system for AI workspaces, productivity
software, internal platforms, developer tools and modern B2B products.

The template lives in [`comlabs-site/`](./comlabs-site) — see
[`comlabs-site/README.md`](./comlabs-site/README.md) for setup, customisation,
image replacement and deployment instructions.

```bash
cd comlabs-site
npm install
npm run dev
```
